# Copilot Code Review

For Elixir changes, use the `elixir-code-review` skill.

Repository conventions, public APIs, tests, and intentional architecture take
precedence over generic recommendations.

Report only findings with a concrete correctness, reliability, security,
operability, or maintainability consequence. Explain the failure mode and the
smallest reasonable correction.

Do not require large unrelated refactors. Human review remains required.
